## 💻 Padrão de Organização

Cada subdiretório de curso segue as seguintes boas práticas:
* **`README.md` individual**: Explicando o objetivo do curso, ferramentas e instruções de execução específicas.
* **`.gitignore` dedicado**: Garantindo que artefatos de build, chaves de ambiente e pastas pesadas (como `node_modules/`) não poluam o repositório.
* **Commits padronizados**: Utilizando padrões semânticos de commit (`feat:`, `fix:`, `docs:`, `refactor:`).
