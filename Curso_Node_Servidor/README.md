# Servidor Backend com Node.js & Express 🚀

Projeto prático focado na criação de servidores backend com Node.js, abrangendo:
1. **Módulo Nativo `http`**: Como a web funciona por baixo dos panos (rotas, headers, status codes e response streaming).
2. **Framework Express.js**: Criação de APIs robustas com middlewares, roteamento avançado e integração com bancos de dados.

---

## 🛠️ Tecnologias

- **Node.js**
- **Módulo Nativo HTTP**
- **Express.js** (próxima etapa)
- **Nodemon**

---

## 🚀 Como Executar

1. Navegue até a pasta:
   ```bash
   cd Curso_Node_Servidor
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor em modo de desenvolvimento:
   ```bash
   npm run start:dev
   ```

4. Acesse no navegador: `http://localhost:8080/home`
